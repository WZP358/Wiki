# 编译错误修复说明

## 问题描述

在实现新功能时遇到了以下编译错误：

1. `softDelete()` 和 `restore()` 方法不存在
2. `OperationLogService.log()` 方法签名不匹配
3. `KnowledgeBaseService.canView()` 方法不存在

## 修复方案

### 1. 软删除方法

**问题：** `BaseEntity` 类没有提供 `softDelete()` 和 `restore()` 方法

**解决方案：** 直接使用 `setDeletedAt()` 方法

```java
// 修复前
template.softDelete();

// 修复后
template.setDeletedAt(java.time.LocalDateTime.now());
```

### 2. 操作日志方法

**问题：** `OperationLogService` 的方法名是 `record()`，不是 `log()`

**原始签名：**
```java
public void record(Long userId, String username, String action,
                  String targetType, String targetId, String ip, String detail)
```

**解决方案：** 更新所有调用

```java
// 修复前
operationLogService.log("CREATE_TEMPLATE", user.getUserId(), ip, "创建模板");

// 修复后
operationLogService.record(user.getUserId(), user.getUsername(), "CREATE_TEMPLATE",
        "TEMPLATE", template.getId().toString(), ip, "创建模板: " + template.getName());
```

### 3. 知识库权限检查

**问题：** `KnowledgeBaseService` 没有 `canView()` 方法

**解决方案：** 使用 `ensureKbVisible()` 方法并捕获异常

```java
// 修复前
if (!knowledgeBaseService.canView(template.getKbId(), user)) {
    throw new BusinessException(ErrorCode.FORBIDDEN, "无权访问");
}

// 修复后
try {
    knowledgeBaseService.ensureKbVisible(template.getKbId(), user);
} catch (BusinessException e) {
    throw new BusinessException(ErrorCode.FORBIDDEN, "无权访问此模板");
}
```

## 修复的文件

1. `DocumentReactionService.java` - 修复软删除和日志记录
2. `DocumentTemplateService.java` - 修复软删除、日志记录和权限检查
3. `DocumentCommentService.java` - 修复软删除和日志记录

## 验证

所有编译错误已修复，代码现在应该可以正常编译和运行。

## 注意事项

在未来添加新功能时，请注意：

1. 检查 `BaseEntity` 的实际方法，不要假设有 `softDelete()` 等辅助方法
2. 查看现有服务类的方法签名，确保参数匹配
3. 使用现有的权限检查方法，如 `ensureKbVisible()` 而不是假设有 `canView()`

# 新增功能文档

## 概述

本次更新为 Wiki 系统添加了多个类似语雀的核心功能，提升了用户体验和协作能力。

## 新增功能列表

### 1. 文档模板系统

#### 功能描述
- 用户可以创建、使用和管理文档模板
- 支持公开模板和私有模板
- 模板按分类组织（会议、项目、技术、产品、汇报等）
- 记录模板使用次数

#### 后端实现

**实体类：** `DocumentTemplate.java`
- 包含模板名称、描述、内容、分类、封面等字段
- 支持软删除

**API 端点：**
```
POST   /api/templates              - 创建模板
GET    /api/templates              - 获取可用模板列表
GET    /api/templates/{id}         - 获取模板详情
PUT    /api/templates/{id}         - 更新模板
DELETE /api/templates/{id}         - 删除模板
GET    /api/templates/category/{category} - 按分类获取模板
POST   /api/templates/{id}/use     - 增加模板使用次数
```

**数据库表：** `document_templates`

#### 前端实现

**组件：** `TemplateSelector.vue`
- 模态框形式展示模板选择器
- 支持按分类筛选
- 卡片式展示模板信息
- 点击模板自动应用到编辑器

**使用方式：**
```vue
<TemplateSelector
  :visible="showTemplates"
  :kb-id="currentKbId"
  @close="showTemplates = false"
  @select="applyTemplate"
/>
```

#### 预置模板
系统预置了 5 个常用模板：
1. 会议纪要
2. 项目计划
3. 技术文档
4. 产品需求文档 (PRD)
5. 周报模板

### 2. 文档评论系统

#### 功能描述
- 支持对文档进行评论和回复
- 支持评论的编辑和删除
- 支持标记评论为"已解决"
- 显示评论作者信息和时间
- 支持嵌套回复

#### 后端实现

**实体类：** `DocumentComment.java`
- 包含评论内容、作者、父评论ID等字段
- 支持点赞计数
- 支持解决状态标记

**API 端点：**
```
POST   /api/docs/{docId}/comments              - 创建评论
GET    /api/docs/{docId}/comments              - 获取文档评论列表
PUT    /api/docs/{docId}/comments/{commentId}  - 更新评论
DELETE /api/docs/{docId}/comments/{commentId}  - 删除评论
POST   /api/docs/{docId}/comments/{commentId}/resolve - 标记评论为已解决
GET    /api/docs/{docId}/comments/count        - 获取评论数量
```

**数据库表：** `document_comments`

#### 前端实现

**组件：** `DocumentComments.vue`
- 显示评论列表和回复
- 支持发表新评论
- 支持回复评论
- 支持编辑和删除自己的评论
- 显示评论时间（相对时间）

**使用方式：**
```vue
<DocumentComments :doc-id="docId" />
```

### 3. 文档反应系统

#### 功能描述
- 支持对文档添加表情反应
- 支持 5 种反应类型：赞、喜欢、鼓掌、庆祝、火
- 实时显示反应统计
- 用户可以切换自己的反应

#### 后端实现

**实体类：** `DocumentReaction.java`
- 记录用户对文档的反应类型
- 唯一约束：同一用户对同一文档的同一类型反应只能有一个

**枚举类：** `ReactionType.java`
```java
public enum ReactionType {
    LIKE,      //  赞
    LOVE,      //  喜欢
    THUMBS_UP, //  鼓掌
    CLAP,      //  庆祝
    FIRE       //  火
}
```

**API 端点：**
```
POST /api/docs/{docId}/reactions/{reactionType} - 切换反应
GET  /api/docs/{docId}/reactions                - 获取反应统计
```

**数据库表：** `document_reactions`

#### 前端实现

**组件：** `DocumentReactions.vue`
- 显示所有反应类型和计数
- 高亮显示用户已添加的反应
- 点击切换反应状态

**使用方式：**
```vue
<DocumentReactions :doc-id="docId" />
```

## 集成指南

### 在编辑器页面集成

```vue
<template>
  <div class="editor-page">
    <!-- 编辑器工具栏 -->
    <div class="toolbar">
      <button @click="showTemplates = true">使用模板</button>
    </div>

    <!-- 编辑器 -->
    <textarea v-model="content"></textarea>

    <!-- 文档反应 -->
    <DocumentReactions :doc-id="docId" />

    <!-- 文档评论 -->
    <DocumentComments :doc-id="docId" />

    <!-- 模板选择器 -->
    <TemplateSelector
      :visible="showTemplates"
      :kb-id="kbId"
      @close="showTemplates = false"
      @select="applyTemplate"
    />
  </div>
</template>

<script setup>
import { ref } from 'vue'
import DocumentReactions from '@/components/DocumentReactions.vue'
import DocumentComments from '@/components/DocumentComments.vue'
import TemplateSelector from '@/components/TemplateSelector.vue'

const docId = ref('123')
const kbId = ref('456')
const content = ref('')
const showTemplates = ref(false)

function applyTemplate(template) {
  content.value = template.markdownContent
}
</script>
```

## API 调用示例

### 1. 创建模板

```javascript
import { templateApi } from '@/api/modules'

const template = await templateApi.create({
  name: '我的模板',
  description: '这是一个自定义模板',
  markdownContent: '# 标题\n\n内容...',
  category: '自定义',
  isPublic: false,
  kbId: '123'
})
```

### 2. 发表评论

```javascript
import { commentApi } from '@/api/modules'

const comment = await commentApi.create('docId', {
  content: '这是一条评论',
  parentId: null // 如果是回复，填写父评论ID
})
```

### 3. 添加反应

```javascript
import { reactionApi } from '@/api/modules'

// 切换"赞"反应
await reactionApi.toggle('docId', 'LIKE')

// 获取反应统计
const stats = await reactionApi.getStats('docId')
console.log(stats.counts) // { LIKE: 5, LOVE: 3, ... }
console.log(stats.userReacted) // { LIKE: true, LOVE: false, ... }
```

## 权限控制

### 模板权限
- 公开模板：所有用户可见
- 知识库模板：知识库成员可见
- 私有模板：仅创建者可见
- 只有创建者可以编辑和删除模板

### 评论权限
- 所有可以查看文档的用户都可以评论
- 只能编辑和删除自己的评论
- 文档作者和管理员可以标记评论为"已解决"

### 反应权限
- 所有可以查看文档的用户都可以添加反应
- 用户可以随时切换自己的反应

## 性能优化建议

1. **评论分页**：当评论数量较多时，建议实现分页加载
2. **反应缓存**：反应统计可以使用 Redis 缓存
3. **模板缓存**：公开模板列表可以缓存
4. **懒加载**：评论组件可以在用户滚动到底部时才加载

## 故障排查

### 常见问题

**Q: 模板列表为空？**
A: 检查数据库是否执行了迁移脚本，确保预置模板已插入。

**Q: 评论无法发表？**
A: 检查用户是否有文档查看权限，检查评论内容是否为空。

**Q: 反应统计不准确？**
A: 清除 Redis 缓存，重新加载统计数据。

**Q: 前端报 404 错误？**
A: 检查后端 API 路由是否正确配置，确保 Controller 已注册。

# Wiki 系统用户逻辑 BDD 说明

## 角色边界

- 访客：未登录用户，只能登录或注册。
- 普通用户：进入用户端，能看到公开知识库、同团队知识库、自己被邀请的知识库。
- 系统管理员：负责平台级治理，包括用户、团队、职位、待分配账号、后台审计和恢复删除内容。
- 知识库管理员：负责单个知识库内部协作，包括邀请普通用户、调整成员权限、创建子知识库、停用知识库和删除文档。
- 知识库编辑者：可在指定知识库内创建和编辑文档。
- 知识库查看者：只能阅读和搜索，不能创建、编辑或删除。

## 用户注册与分配

```gherkin
Feature: 用户注册后进入待分配流程
  Scenario: 新用户注册成功
    Given 访客填写注册信息并输入验证码
    When 注册成功
    Then 系统创建普通用户账号
    And 用户默认没有团队、职位和知识库协作权限
    And 管理员可以在待分配用户页面看到该账号
```

```gherkin
Scenario: 系统管理员分配新用户
  Given 一个新注册用户处于待分配状态
  When 系统管理员为其设置团队、职位和知识库权限
  Then 用户可以在用户端看到公开知识库、同团队知识库和被邀请的知识库
  And 用户按知识库成员角色执行查看、编辑或管理操作
```

## 可见不等于可编辑

```gherkin
Feature: 知识库可见但不一定可编辑
  Scenario: 用户不是公开知识库成员
    Given 一个公开知识库
    And 当前用户不在该知识库成员名单中
    When 用户打开该知识库
    Then 用户可以阅读公开内容
    But 用户不能新建、编辑、删除文档
```

```gherkin
Scenario: 用户是团队知识库同团队成员但未加入协作名单
  Given 一个团队知识库属于用户所在团队
  And 当前用户不在该知识库成员名单中
  When 用户打开该知识库
  Then 用户可以按可见规则阅读
  But 用户不能创建或编辑文档
```

```gherkin
Scenario: 用户不是私有知识库成员
  Given 一个私有知识库
  And 当前用户不在该知识库成员名单中
  When 用户尝试打开该知识库
  Then 系统拒绝访问
```

## 知识库成员权限

```gherkin
Feature: 知识库成员角色控制协作能力
  Scenario: 创建知识库
    Given 一个已登录普通用户
    When 用户创建知识库
    Then 系统将该用户加入知识库成员名单
    And 该用户在此知识库中的角色为管理员
```

```gherkin
Scenario: 知识库管理员邀请普通用户
  Given 当前用户是知识库管理员
  And 被邀请对象是普通用户
  When 管理员按账号或邮箱邀请该用户
  Then 被邀请用户加入知识库成员名单
  And 被授予查看、编辑或管理权限
```

```gherkin
Scenario: 阻止最后一名管理员被降级
  Given 一个知识库只有一名管理员
  When 管理员尝试把自己或唯一管理员降级
  Then 系统拒绝操作
  And 提示每个知识库至少需要保留一名管理员
```

## 子知识库

```gherkin
Feature: 知识库下可以创建子知识库
  Scenario: 知识库管理员创建子知识库
    Given 当前用户是父知识库管理员
    When 用户在父知识库中创建子知识库
    Then 系统创建一个带 parentId 的新知识库
    And 创建者成为子知识库管理员
    And 用户点击子知识库时跳转进入子知识库首页
```

```gherkin
Scenario: 子知识库权限独立维护
  Given 一个父知识库下存在子知识库
  When 用户能看到父知识库
  Then 不代表用户自动拥有子知识库编辑权限
  And 子知识库仍按自己的可见范围和成员角色判断权限
```

## 文档协作

```gherkin
Feature: 文档操作由知识库成员角色决定
  Scenario: 查看者尝试新建文档
    Given 当前用户对知识库只有查看权限
    When 用户点击新建文档
    Then 前端提示只读权限
    And 后端拒绝创建请求
```

```gherkin
Scenario: 编辑者创建文档
  Given 当前用户是知识库编辑者
  When 用户创建文档并保存
  Then 系统保存文档内容
  And 生成版本历史
  And 刷新最近更新缓存
```

```gherkin
Scenario: 管理员删除文档
  Given 当前用户是知识库管理员
  When 用户删除文档
  Then 文档被软删除
  And 普通用户不再看到该文档
  And 系统管理员仍可在后台看到并恢复
```

```gherkin
Scenario: 编辑锁保护
  Given 用户 A 正在编辑文档
  When 用户 B 打开同一文档
  Then 用户 B 进入只读状态
  And 用户 B 可以点击催一下提醒用户 A
```

## 系统管理员边界

```gherkin
Feature: 系统管理员负责平台治理
  Scenario: 系统管理员进入后台
    Given 当前用户角色为系统管理员
    When 用户打开后台管理系统
    Then 可以管理用户、团队、知识库、文档审计和恢复
```

系统管理员拥有兜底治理权限；普通业务协作仍以知识库成员角色为主。
